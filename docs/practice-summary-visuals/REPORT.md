# Practice summary — ภาพประกอบเส้นคม

วันที่ 14 ตุลาคม 2026

ภาพเดิมเป็น `codi-win.svg` จริง แต่เป็นเส้น contour ที่ trace จาก PNG ขนาด 128px พร้อม Gaussian blur 0.4px ไม่ใช่ภาพ PNG ฝังใน SVG

ผู้ใช้อนุมัติให้ภาพเส้นคมแทนท่าชนะหลักแล้ว จึงย้ายภาพนี้มาเป็น `app/assets/sprites/codi-win.svg` ผ่าน `PLAYER_POSES.win` ร่วมกันทั้ง popup สรุปการซ้อมและภาพประกอบอันดับว่าง รวมรายการ Elements ให้เหลือท่าชนะรายการเดียว และลบชื่อไฟล์/รายการ `codi-win-summary` ที่แยกไว้ก่อนหน้า

ภาพนำรูปทรงเวกเตอร์สะอาดจาก `codi-down.svg` มาใช้กับท่าตาขยิบ ยกแขน และรองเท้าข้างหนึ่งเอียง ไม่มีภาพฝังหรือ blur: 4,922 bytes, 63 SVG elements, viewBox 128×128 เก็บท่าชนะ trace เดิมใน `docs/codi-svg/reference/codi-win-traced.svg` สำหรับอ้างอิงผลวัดเก่า ไม่แก้ท่าเดิน/แพ้ทั้ง 5 ท่า

เพิ่มขนาดแสดงผลจาก 104px เป็น 144px พร้อมดาว SVG 3 ดวงขนาด 28/21/14px, แสงพื้นหลัง, วงโคจร และวงรองรับใต้ตัว ดาวค่อย ๆ สว่าง/หรี่และโยกเล็กน้อย; reduced motion หยุด animation ทั้งหมดที่เพิ่มใหม่ จอเตี้ยใช้ภาพ 96px ในกรอบ 100px

![ภาพประกอบใหม่ในเฟรมปกติ ขยาย 3 เท่า](D:/CodeVenture/debug-master/docs/practice-summary-visuals/hero-preview.png)

ภาพนี้เป็น **static asset composition** ตามรูปทรง/ตำแหน่ง hero ไม่ใช่ screenshot จาก browser ได้ตรวจ SVG render ที่ 128px และ 512px พร้อม composition นี้แล้ว: เส้นหมวก หน้าจอ ตา ลำตัวและรองเท้าคม ไม่มีการตัดแขน/เท้า ดาวไม่บังตัวละคร

หัวข้อ “สรุปผลการซ้อม” และ brand อยู่กึ่งกลาง ส่วนเวลา/ด่านที่ผ่าน/เดินผิด ปุ่มกลับหน้าแรก focus และพฤติกรรม dialog คงเดิม

เกณฑ์ SSIM ≥98% ที่บันทึกใน `docs/codi-svg/` ยังอ้างถึงชุด 6 ท่าเดิม **ไม่ได้ใช้รับรองท่าชนะเส้นคมที่ผู้ใช้เลือกแทนนี้** งานนี้ตรวจความคมด้วยการเรนเดอร์และดูภาพ ไม่ได้คำนวณ SSIM ใหม่ และไม่ได้ตรวจ popup/animation ใน browser

`pnpm build` ผ่าน ไม่เขียน/รัน test, ไม่ git add/commit และไม่เพิ่ม dependency
